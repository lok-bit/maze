# Random Maze Exploration Game

This is a maze exploration game built with **Flutter**. Players navigate through a randomly generated maze under a limited field of view, racing to finish in the shortest time possible. The game includes a **timer**, **ranking system**, and **adjustable visibility radius**, making it a compact but feature-rich demo of Flutter UI and logic.

---

## 🔧 Technologies Used

- **Flutter / Dart**
- Random Maze Generation Algorithm
- Custom Fog-of-War (Field of View Limitation)
- Firebase Realtime Database (for storing leaderboard data)

---

## 🎮 Game Features

- **Random Maze Generator**: Each playthrough offers a different maze layout.
- **Adjustable Vision Radius**: Players can customize the visible range to increase difficulty.
- **Time Tracking**: Real-time stopwatch tracks player's completion time.
- **Leaderboard**: Top scores are stored and retrieved via Firebase.

---

## 🚀 Getting Started

1. Install [Flutter](https://flutter.dev/docs/get-started/install)
2. Clone this repository
3. Run `flutter pub get`
4. Launch with `flutter run` using a simulator or physical device

> If you want to enable the leaderboard, make sure to configure your Firebase project and include the `google-services.json`.
